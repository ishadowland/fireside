# Conversation Archives

> 需求澄清对话原文归档

## Format

Each file in this directory captures one full conversation between user and agent during the requirements-clarification phase. Files are timestamped `YYYY-MM-DD-NN-<topic>.md`.

## Purpose

- **Audit trail**: trace why each decision was made
- **Onboarding**: new contributors can read conversations to understand context
- **Re-decision**: if a decision is challenged later, the original reasoning is preserved

## Privacy Note

These files may contain user preferences, names, or platform-specific details. **Do not publish verbatim transcripts to public channels without redaction.** In this repo, store them in the public archive only if the user has consented to public documentation. For private iterations, keep them locally and reference hashes here instead.
